STE-Commerce

Featured project

STE-Commerce is an e-commerce storefront and demonstration project I built to explore marketplace design and practical web development. It includes a categorized product storefront and an admin dashboard for managing product listings, including adding, editing, and removing products. This project demonstrates the core store experience without representing a commercial business; additional testing and production-ready features would be needed before using it in a live commercial operation.
